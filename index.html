Fahrzeug ins Website-Projekt übernehmen
  1. ZIP in einen separaten Ordner entpacken.
  2. Im Terminal den Website-Ordner öffnen und diesen Befehl ausführen:
  3. npm run vehicles:transfer
  4. Den entpackten Ordner ins Terminal ziehen und Eingabetaste drücken. Bei einem bestehenden Fahrzeug das angezeigte Original mit seiner Nummer auswählen.
  5. Im Terminal mit JA bestätigen. Die Übernahme erstellt eine Sicherung und bereitet die Vorschau vor. Nicht selbst kopieren oder alte Fahrzeugdateien löschen.
  6. Zum Ansehen npm run dev im Website-Ordner starten. Eine laufende Vorschau wird nach der Übernahme automatisch neu gestartet; danach die Browserseite neu laden.
  7. Danach npm run build ausführen. Für die GitHub-Pages-Vorschau npm run build:pages verwenden. Die Fahrzeugliste im Editor anschließend aktualisieren.

Der Assistent erkennt die neue Kategorie aus der ZIP. Bestehende Fahrzeuge werden erst nach Ihrer Auswahl und Bestätigung ersetzt. Bei einem Kategoriewechsel entfernt er das alte Fahrzeugpaar und richtet Weiterleitungen für deutsche und englische URLs ein. Die ZIP allein enthält keine Weiterleitungen.

Der Build aktualisiert die lokale Website-Ausgabe, veröffentlicht sie aber nicht.
